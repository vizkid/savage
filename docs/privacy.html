Savage Privacy Policy

Last updated: 2026-07-22

Savage converts SVGs into PNG images on their way into Google Slides. Everything happens locally in your browser.

Clipboard

When a Google Slides tab gains focus (or you press Ctrl/Cmd there), Savage reads your clipboard to check whether it holds an SVG. If it does, the SVG is converted locally and the clipboard is rewritten with the resulting PNG plus the original markup. Clipboard contents are processed in memory only, never stored, logged, or transmitted anywhere.

Storage

One number is saved in Chrome's extension storage: your chosen output size. Nothing else is stored.

Network

Savage makes no network requests, with one exception: when you drag an SVG image from another website into Slides, the extension fetches that image's URL to get the SVG (for Wikipedia/Wikimedia pages this includes a MediaWiki API lookup to locate the file). Nothing about you or your documents is sent, only the request for the file you just dragged.

Optional permission

By default Savage has no access to websites' data. The optional "fetch from any site" setting grants host access solely so dragged-URL fetches work on sites that block cross-origin requests. It is off unless you enable it, and you can revoke it in the popup at any time.

What Savage does not do

  • No analytics, telemetry, or tracking of any kind
  • No accounts, no server, no data collection
  • No selling or sharing of data (there is no data to sell)
