Savage · Chrome extension for Google Slides

Paste SVGs into Google Slides as editable shapes.

Google Slides can't paste or drop SVGs. Savage converts them on the way in: copy an SVG or drag one onto a slide and it lands as editable Slides shapes. Paths, basic shapes, gradients, and text (converted to outlines) all become native shapes, grouped into one object you can move, resize, and connect in a diagram.

When part of an SVG can't be a shape, such as an embedded bitmap or a filter, that SVG falls back to a transparent PNG instead, so a paste always produces something. It runs locally; the only network requests are fetching an SVG you drag from a site and fetching a font from Google Fonts when an SVG's text needs one.

Add to Chrome Free. Open any Slides deck to use it.

Slides only · Chrome only · No tracking

Chrome asks for clipboard access once so conversion can happen before you paste.
